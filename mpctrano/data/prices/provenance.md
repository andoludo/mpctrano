# Cached price samples

Each section names one `<name>.csv` file (columns `time` in local time Europe/Brussels, naive, and
`price_eur_mwh`), its source, licence and download date. Files are produced by
`tutorials/scripts/fetch_prices.py`; do not edit them by hand.
